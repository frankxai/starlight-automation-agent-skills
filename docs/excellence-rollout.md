# Rollout: staged adoption, not assumed universal enforcement

1. Merge reviewed source after validator and public safety checks.
2. Locate the actual agent-rule synchronizer and its source of truth. Make change there under a separate reviewable PR. Do not assume this repository owns sync.
3. Install account-wide short ChatGPT Custom Instructions through the user's Personalization UI. Confirm with two independent new-chat experiments.
4. Enable excellence skill in validated harnesses through their documented skills or instruction interfaces; record loaded commit SHA per harness.
5. Add one production software factory task and one GenCreator media task, with independent acceptance receipts and no uncontrolled cloud spending.
6. Conduct blinded preference testing on 6 initial benchmark tasks; expand to 20 only after establishing baselines and agreement.
7. Connect discipline-specific plugins only where they already own that workflow; avoid a global plugin auto-invocation claim.
8. Monitor acceptance, verified-completion rate, rework, defect escape rate, factual reliability, user preference and cost per accepted artifact.

Expected evidence: harness-load receipt, benchmark records, PR/commit, build/test logs, actual deployment URL where applicable and qualitative expert review.
